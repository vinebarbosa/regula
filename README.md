# Regula


## 🚀 Instruções para rodar o projeto

1. Instale as dependências e configure o ambiente:
   ```bash
   sudo npm run setup
   ```

2. Navegue até o aplicativo web e inicie o servidor de desenvolvimento:
   ```bash
   cd apps/web
   pnpm dev
   ```

✅ Pronto! O projeto estará rodando em [https://local.homologacao.regulav2.lais.ufrn.br:3000](https://local.homologacao.regulav2.lais.ufrn.br:3000)
